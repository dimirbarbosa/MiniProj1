# MiniProj1 – Currículo em SPA (Vue 3)

Miniprojeto da Tarefa 2.2 – Programação Web Avançada (Mestrado em Engenharia Informática e Tecnologia Web, UAb/UTAD).

**Autor:** Dimir Barbosa

## O que é
Single Page Application num único `index.html` com Vue 3 (via CDN). Três vistas — «Quem Sou Eu?», «O que faço?» e «Hobbies» — trocam sem recarregar a página; cabeçalho e rodapé são comuns. Cada vista tem endereço próprio (`#/quem-sou-eu`, `#/o-que-faco`, `#/hobbies`), por isso Voltar/Avançar funcionam. Os Hobbies abrem uma janela modal reutilizável. O rodapé tem ícones de redes sociais.

## Como abrir
Duplo clique em `index.html` (precisa de internet para carregar o Vue por CDN). Não requer servidor nem build.

## Ficheiros
- `index.html` – aplicação
- `Wireframes_Dimir_Barbosa.pdf` – wireframes (desktop, móvel e modal)
